# بناء APK من الهاتف فقط

هذه النسخة مجهزة للبناء السحابي عبر GitHub Actions.

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع محتويات هذا المجلد إلى المستودع (وليس ملف ZIP نفسه).
3. افتح تبويب Actions.
4. اختر Build Android APK.
5. اضغط Run workflow.
6. بعد اكتمال البناء افتح صفحة التشغيل، ثم قسم Artifacts.
7. نزّل ملف مساعد-المدرس-الذكي-APK.zip وافتحه، ثم ثبّت app-debug.apk على الهاتف.

لا يحتاج المشروع إلى كمبيوتر أثناء البناء؛ GitHub هو الذي ينفذ عملية البناء.
