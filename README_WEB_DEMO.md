# مساعد المدرس الذكي — الإصدار v20

نسخة ويب محلية متقدمة لإدارة الطلاب والمجموعات والحضور والاختبارات والمالية والجدول وولي الأمر والمهام، مع **مركز تحكم ذكي** جديد.

## إضافات v20
- متابعة الواجبات مع تاريخ تسليم وحالة مكتمل/متأخر.
- مركز تنبيهات مستقل.
- تقويم شهري يعرض الواجبات والتنبيهات والحصص.
- تحليلات سريعة للطلاب والمجموعات والمدفوع والمتبقي والحضور.
- توصيات يومية تلقائية.
- استمرار العمل محليًا بدون خادم.
