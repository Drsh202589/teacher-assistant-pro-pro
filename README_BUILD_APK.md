# بناء APK - مساعد المدرس الذكي

هذه النسخة جاهزة للبناء كتطبيق Android حقيقي باستخدام Capacitor 7.

## أسهل طريقة

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. اجعل الفرع اسمه `main`.
3. افتح تبويب **Actions**.
4. شغّل Workflow باسم **Build Android APK** من زر **Run workflow**.
5. بعد انتهاء البناء افتح الـArtifact باسم `teacher-assistant-apk` وحمّل `app-debug.apk`.
6. ثبّت APK على هاتف Android.

## ما يتضمنه التطبيق

- اسم التطبيق: مساعد المدرس الذكي
- App ID: `com.mostafaelderey.teacherhelper`
- اختيار رقم الطالب من جهات اتصال الهاتف.
- اختيار رقم ولي الأمر من جهات اتصال الهاتف.
- صلاحية READ_CONTACTS تُطلب عند أول استخدام لدفتر الهاتف.
- نسخة الويب تبقى آمنة: إذا فُتحت في المتصفح تظهر رسالة أن اختيار جهات الاتصال المباشر يحتاج تطبيق Android.

## ملاحظة

ملف APK لا يمكن توليده داخل بيئة ChatGPT الحالية لعدم توفر Android SDK/Gradle محليًا. الـWorkflow المرفق يقوم بالبناء على خادم GitHub الذي يوفر Android SDK.
